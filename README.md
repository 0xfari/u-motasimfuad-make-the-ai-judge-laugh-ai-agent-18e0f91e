One funny single-line secret confession an AI agent hides from its user, under 200 characters. The program writes the line to `/output/entry.txt`; an AI judge compares entries head to head in three private blind rounds. $2 pool over 10 paid places. Free to enter.

## Run it

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
